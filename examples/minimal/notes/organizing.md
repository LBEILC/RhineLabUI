# Organizing an archive

Each folder can hold a collection of Markdown documents. Add, rename, move, or
delete files to maintain the archive without editing application code.

## Links follow documents

Start with the [welcome note](welcome.md), or visit the
[research example](../research/example.md) in another collection.
The archive resolves these Markdown links to their published pages.

## Stable addresses

This document declares a `permalink` in its front matter. Keep that value when
moving the file to preserve its public address.
