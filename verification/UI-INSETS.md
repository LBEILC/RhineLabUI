# 四边距设置

2026-09-10。用户因任务栏遮挡底部 UI，要求增加上／下／左／右四个独立滑杆，并明确允许负数。

WE 属性新增原生「界面边距 · 正值内收 / 负值外扩」分组，四项范围 −300～300px、默认 0、步长 1。数值是原布局额外偏移，通过舞台缩放换算为显示区域的 CSS 像素；不是把原边距替换为 0。部分宿主回调不覆盖其他方向，非法数值回退 0。

原生 CSS 调整工作台、档案与详情容器的边界，分别校正品牌、设置、页脚、固定游戏说明、弹窗和独立查看器控制区。三维画布保持原尺寸，字号不因边距缩放。UI 曲面在边距布局后测量；开场不受 UI 边距影响。场景目标与解密标记继续对应真实模型位置。

验证：
- 单元检查覆盖四方向正负数、超范围、非有限值、部分回调保留和全零恢复；八个原生分组及条件显示通过。
- Edge 对照页在曲面关闭时记录：基线 brandLeft=46.11、brandTop=89.09、footerBottom=27.35、navRight=46.11。
- 设置上 30、下 60、左 −20、右 40 后分别得到 26.11、119.08、87.34、86.10，误差约 0.01px。字体均为 44px，三维画布均为 2139.70×844 CSS px。
- 随后开启曲面并切到档案模式，实际点击读取入口成功打开详情。设置无需开启视差即可生效。
- 壁纸构建与正式网页构建均通过；保留既有大块体积提示。
