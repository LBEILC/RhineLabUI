# 精细动效与 main 整合

2026-09-20，将 main `17a1611` 合入精细动效分支。保留主题、超级性能模式、渲染复用、阵列覆盖、壁纸入口和场景释放逻辑；动效按 15 个分项控制。

## 控制关系

- 首次无本站偏好时跟随系统；已保存分项优先，其次为旧版 `reduced`。完整／减少／自定义标签从实际分项推导。
- 页脚数字时钟和悬停编号使用数字滚动开关；工作台既有 `createRollingText`（时钟、媒体、计时器）使用文字滚动开关。
- 主题、工作台显隐、三维场景显隐和自定义背景过渡使用窗口过渡开关；HUD 指针移动使用指针视差开关，并保留 HUD 自身设置与仅 UI 视差限制。
- 音乐律动、小游戏及屏幕动态纹理继续使用整体减少状态（所有分项关闭时），并保留自身开关。场景整体减少状态通过 getter 推导，不维护第二份状态。
- 壁纸宿主的旧 `reduced` 属性转换为完整／减少预设，实时同步打开的设置。原有对照页 `setReduced` 兼容入口同样转换分项。
- 模型解密和正文揭示独立，解密物理时间轴保持运行；主题颜色与清晰度同时应用。场景释放后的空值保护和查看器稳定引用继续保留。
