# 音乐归齐与强调色修正

2026-09-10。

壁纸的短交互声音也可能进入 WE 系统频谱。播放本地音效时记录实际音符结束时间与 200ms 回传余量，在尚未形成音乐活动时忽略该时间内的新频谱活动；已有音乐继续响应。音乐强度为零时不驱动归齐。

归齐进度同时控制阵列与选中标签的强调程度，完全归齐时无强调色。暗色“仅选中强调”根据当前档案实际升降插值，新选中与归位副本均连续更新。

scripts/check-local-sound.mjs 复现未过滤时的假音乐起点，验证自身声音抑制、持续音乐起动与保留、信号丢失回落。scripts/check-selection-state.mjs 在 Edge 1600×900 使用实际鼠标拖动与模拟宿主频谱，验证静音拖动 flatten=0、新旧档案强调色出现中间值、全部归齐无强调及恢复；截图与结果在 verification/selection-state/。通过的是模拟回传测试，混合系统音源的最终表现以 WE 实际使用为准。

用户本轮决定保留原版、连续频谱、层叠流波三种音乐律动供自行选择，默认原版。
